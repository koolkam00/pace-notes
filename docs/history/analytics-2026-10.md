## Home sections: the chapter-* note (line 139)

**The home page has no `chapter-*` sections from this change.** `autopilot/metrics.md` defines `home_depth@v1` as the distinct `chapter-*` sections a home landing saw, and counts "at least 3 distinct home chapters" (`section_viewed` on `/` with a `chapter-*` id) as an answer signal in `answered_visit_rate@v1`, `one_page_no_action_rate@v1` and `home_continuation_rate@v1`. From the day this ships, `home_depth@v1` no longer applies to `/` (every home landing reads 0), and home landings can no longer earn that answer signal: `answered_visit_rate@v1` and `home_continuation_rate@v1` fall and `one_page_no_action_rate@v1` rises for that reason alone, against this change, never in its favour. The new ids are deliberately not `chapter-*`: three short sections would have made the signal nearly automatic. Only the owner can add `@v2` definitions (for instance counting `section_viewed` `result` on `/tools/plan`); the measurement plan is in [the project handoff](handoff-2026-10-14-to-17.md#storybrand-home-page-navigation-and-research-hub-october-16-2026).
