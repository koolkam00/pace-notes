# History

Dated records that no longer describe the project as it is, kept so that earlier evidence, decisions and reasoning stay readable. The current state is in the [project handoff](../PROJECT_HANDOFF.md); the contracts are in the documents it links; the owner's decisions are in the [register](../OWNER_DECISIONS.md).

## Rules for this folder

- A file here is a copy of what its source said at the commit named below. It is never rewritten. It may gain a one-line banner at its top and dated corrections (`**Correction (YYYY-MM-DD):** …`), nothing else.
- To move text here, copy it with `git show <sha>:<path>`, sliced by line, never retyped. Re-point its relative links for this folder, and to the new home of any section that moved, and change nothing else, except that a line longer than 2,000 characters may be wrapped at sentence ends outside tables and headings, with its words unchanged, when the file's banner says so. Add a row to the table below. Update every inbound link and anchor in the same commit, then run the [link and anchor check](../OPERATIONS.md#the-link-and-anchor-check).
- Cite a commit on `main` whenever the moved lines are the same there, so `git show` reproduces them from any clone. A commit that exists only on a branch is marked with that branch; `main` is squash-merged, so after the merge fetch the branch (`git fetch origin <branch>`; branches are kept) or the pull request's head (`git fetch origin pull/<number>/head`) to reproduce it.
- Counts here belong to the release they name (1107, 0934, 1652 and so on). Do not quote them as current.
- Older material is in Git history (`git log --follow -- <path>`) and in the immutable releases.
